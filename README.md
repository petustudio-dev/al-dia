# Al Día

Noticias de Colombia y el mundo, resumidas y actualizadas dos veces al día (6:16 a.m. y 6:16 p.m., hora Colombia).

- Sitio: https://petustudio-dev.github.io/al-dia/
- Las ediciones viven en `data/editions/` y el índice en `data/index.json`; los genera automáticamente una tarea programada de Claude.
